# Udsigt scenes

The public scene library for Udsigt, the live wallpaper app for Mac. The app reads `index.json` and downloads
`.lcscene` files from here, so scenes can be added and updated without reinstalling the app.

| Scene | |
|---|---|
| **Aarhus Ø** (v4, for current Udsigt; older app versions get v3 or v2) — the harbour skyline from a pier on the north shore, with boats, kayaks, swimmers, ducks and gulls. Comes with the app. | ![](aarhus.jpg) |
| **Living Coast** (v2, for current Udsigt; older app versions get v1) — dunes and marram grass above a quiet beach, looking south over the sea towards a line of wind turbines | ![](coast.jpg) |
